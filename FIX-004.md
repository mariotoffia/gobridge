# FIX-004 — Split `domain/` into bounded-context sub-packages

> Carved out of `FINAL_DDD_HEX_CLEAN_FIX_PLAN.md` for a dedicated
> session. The other 8 FIX tasks (FIX-001/002/003/005/006/007/008/009)
> shipped in the April 2026 sprint; this one was deferred because it
> rewrites every `domain.X` reference in the codebase and is best done
> in a focused session of its own.

## Why this exists

`domain/` is currently a single flat package mixing routing,
persistence, and connectivity vocabulary. `RoutePolicy`,
`OutboxRecord`, and `SessionMode` all live in one namespace, which
hides the fact that they belong to different bounded contexts. Strict
DDD demands separate packages with their own ubiquitous language and
explicit boundaries — so accidental cross-context coupling becomes a
compile error rather than a code-review judgement call.

After this refactor, a routing file that reaches into a persistence
type fails the build. That is the value: the architectural concept
becomes machine-checked.

## Current state (snapshot at FIX-009)

`domain/` ships **4,207 LOC** across 9 production files plus tests.
9 files, types per file (with the bounded context they belong in):

| File | Types / functions | Bounded context |
|---|---|---|
| `domain/credentials.go` | `CredentialKind`, `PasswordCredential`, `TLSMaterial`, `CredentialSet` | `connectivity` (or its own `security`?) |
| `domain/drain_strategy.go` | `DrainStrategy` interface, `FixedPoll`, `AdaptiveBackoff`, default policies | `persistence` |
| `domain/envelope.go` | `Envelope`, `OutboxStatus`, `OutboxRecord`, `OutboxPartitionKey` | mixed: `messaging` (Envelope) + `persistence` (OutboxStatus, OutboxRecord) |
| `domain/errors.go` | `ErrorClass`, `ErrorCode`, `BridgeError` + sentinels | `shared` |
| `domain/headers.go` | reserved-header helpers | `messaging` |
| `domain/lease.go` | `LeaseToken`, `LeaseInfo`, `PeerInfo` | `persistence` |
| `domain/metrics.go` | `Tag` + metric-name constants | `shared` |
| `domain/route.go` | `DeliveryMode`, `DispatchMode`, `SessionMode`, `AckBoundary`, `BackoffPolicy`, `RoutePolicy`, `DispatchPlan`, `DestinationBinding`, `SubscriptionPlan` | mixed: `routing` + `connectivity` (SessionMode, SubscriptionPlan) |
| `domain/tracecontext.go` | `TraceContext`, parse/format/extract/inject | `messaging` |
| `domain/clock/` | already its own sub-package | (unchanged) |

External callers: **438 .go files** (production + tests) reference
`domain.X` somewhere. That's the scope of the rename.

## Target structure

Per the original plan:

```
domain/
├── shared/         # primitives crossing all contexts
├── messaging/      # Envelope, Headers, TraceContext, ErrorClass tags
├── persistence/    # OutboxRecord/Status, DLQEntry, LeaseToken, LeaseInfo, DrainStrategy
├── routing/        # RoutePolicy, BackoffPolicy, DispatchPlan, DestinationBinding
├── connectivity/   # SessionMode, SessionPlan, SubscriptionPlan, CredentialSet (?)
└── clock/          # (unchanged)
```

`shared/` holds `BridgeError`, `Tag`, `ErrorClass`, `ErrorCode` —
anything every context legitimately needs. The arch lint must allow
every other domain context to depend on `shared` but **not on each
other**.

Cross-context references inside the inner ring are forbidden by the
new component rules: a routing file that needs an `Envelope` must
receive it via the application layer, not import `messaging` directly.
That catches accidental coupling.

## Step-by-step approach

### Phase 0 — Preparation

1. Confirm baseline: `make check` is green at HEAD. The two carve-out
   plans (this one + `FIX-006.md`) are committed but no domain code
   has moved.
2. Note the per-context type list above and decide the final
   placement for the **mixed** files (envelope.go, route.go).
   Recommended split:
   - `domain/messaging/envelope.go` ← `Envelope`, headers helpers
   - `domain/persistence/outbox.go` ← `OutboxStatus`, `OutboxRecord`,
     `OutboxPartitionKey`
   - `domain/routing/policy.go` ← routing-specific types
   - `domain/connectivity/session.go` ← `SessionMode`,
     `SubscriptionPlan`, route-session config
3. Set up a per-context branch strategy: one bounded context per
   commit. The mechanical sed work is large enough that splitting it
   keeps each commit reviewable.

### Phase 1 — Move `domain/shared` (smallest, foundational) - DONE

`shared` is the foundation every other context will import. Move it
first so the dependency graph stays acyclic.

1. Create `domain/shared/`.
2. `git mv domain/errors.go domain/shared/errors.go` (re-name the
   `package domain` declaration to `package shared`).
3. `git mv domain/metrics.go domain/shared/metrics.go` (same).
4. Update `.go-arch-lint.yml`:
   ```yaml
   components:
     domain_shared: { in: [domain/shared, domain/shared/**] }
   deps:
     domain_shared:
       canUse: [_no_external_deps_]
   ```
   And update the existing `domain` rule to allow it during the
   transition.
5. Bulk-rename across the codebase:
   ```bash
   grep -rl 'domain\.\(BridgeError\|ErrorClass\|ErrorCode\|Tag\|Err[A-Z][a-zA-Z]*\|Metric[A-Z][a-zA-Z]*\|TagKey[A-Z][a-zA-Z]*\)' \
     --include="*.go" | grep -v '^domain/' | grep -v '/scripts/' \
     | xargs -I{} bash -c 'goimports -l {}'
   ```
   Then sed-replace `domain.BridgeError` → `shared.BridgeError`
   (and so on for every shared symbol). `goimports` adds the
   `domain/shared` import where needed.
6. `make lint && make test` — must be green.
7. Commit: `FIX-004 phase 1: extract domain/shared`.

### Phase 4 — Move `domain/routing` and `domain/connectivity`

Split `route.go`. `SessionMode` and `SubscriptionPlan` go to
`connectivity`; everything else to `routing`. `credentials.go` likely
joins `connectivity` (TLS material is connection-shaped) — but
consider a `domain/security` if it grows.

### Phase 5 — Tighten arch lint and remove the transitional `domain` component

After all five contexts are extracted, remove the catch-all `domain`
component from `.go-arch-lint.yml` and assert via
`scripts/lint-arch-mapping-test.sh` that:
- a sentinel routing type maps to `domain_routing`
- a sentinel persistence type maps to `domain_persistence`
- etc.

The cross-context dependency rules:
```yaml
deps:
  domain_shared:        { canUse: [_no_external_deps_] }
  domain_messaging:     { mayDependOn: [domain_shared] }
  domain_persistence:   { mayDependOn: [domain_shared] }
  domain_routing:       { mayDependOn: [domain_shared, domain_messaging] }
  domain_connectivity:  { mayDependOn: [domain_shared] }
```

`routing` may depend on `messaging` because a `RoutePolicy` references
the `Envelope` type it routes. No other cross-context edge is
permitted; if you need one, the architecture is wrong.

### Phase 6 — Update `.golangci.yml` depguard

Each `domain/<context>/` directory gets its own depguard rule banning
imports of the other contexts (with the exceptions listed above).
This belt-and-suspenders the rule at file level.

## Cost estimate

Realistic effort: **2–3 dedicated days** of focused work.
- Phase 1 (shared): half a day
- Phase 2 (messaging): full day (highest fan-out)
- Phase 3 (persistence): half a day
- Phase 4 (routing + connectivity): half a day
- Phase 5–6 (lint tightening): half a day

Each phase MUST end with `make lint && make test` green before
commit. A failing intermediate state will block subsequent phases
because `goimports` will have stale import paths to fix.

## Risks and how to mitigate

- **Sed catches the wrong substring.** Lesson from FIX-003: macOS
  `sed` doesn't support `\b`; use `[[:<:]]X[[:>:]]` instead.
  Verify each phase with `git diff --stat` and a spot-check `grep`
  for unexpected `<prefix>.X` patterns (e.g., `fileconfig.X` wrongly
  becoming `fileports.X`).
- **Test fixtures use bare type names.** Tests inside the moved
  package `domain.Envelope{...}` become `messaging.Envelope{...}`.
  `goimports` handles the import; sed handles the type prefix.
- **`go.work` updates.** Adding sub-packages doesn't change `go.work`
  (they share the root module). Verify with `go list ./domain/...`.
- **Cross-context circular dep.** If `routing` and `messaging` end up
  needing each other, the design is wrong; surface the missing
  abstraction (e.g., move shared types to `domain/shared`) rather
  than relax the rule.
- **Public API break.** This rewrites `domain.X` for every external
  consumer of the gobridge module. Document the rename in a CHANGELOG
  entry and the version bump.

## Acceptance

- `domain/` no longer has a single flat package; cross-context
  references are explicit.
- The lint mapping test verifies each sub-context.
- `make check` green at every commit boundary.
- A trial violation (deliberately importing `domain/persistence` from
  `domain/routing`) fails `make lint-arch`.
- Code reads better: routing files no longer mention persistence
  primitives directly; they receive translated types from the
  application layer.

## When NOT to start

- When you have less than 3 hours of focused time. Each phase needs
  to land green; an interrupted sed leaves the codebase
  half-renamed and blocks every other PR.
- When there are unmerged feature branches that touch `domain/`. The
  rename will conflict with every one of them. Coordinate the
  freeze.
